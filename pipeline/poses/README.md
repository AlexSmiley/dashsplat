# Whole-drive ego trajectory

From the Reality Splat root on anomastudio: `bash pipeline/poses/run.sh`. Uses the existing Python environment (NumPy, SciPy, OpenCV, Matplotlib) and Ceres from `brew install ceres-solver cmake`. CPU only, up to 14 worker threads. `RS` overrides the default root. Input camera parameters, masks and exposure timing come from `pipeline.common.rig.load_rig()`. Camera mounts, distortion and clocks stay fixed.

**Products:** `poses/ego.npz` (offline), `poses/ego_causal.npz` (bounded-lag forward estimator), `poses/debug/` and the measurement report. Open the live product explicitly with `Trajectory('poses/ego_causal.npz')`; the default selects offline. `T_world_ego` is rear-axle-ground ego → ENU; times are the input master clock. `sigma_pos` (metres) and `sigma_rot` (radians) are **local quality proxies**, not calibrated absolute covariances. `n_tracks` is the number of distinct local BA landmarks offline or consistent past-landmark resection tracks live. `quality_flag` is a bitmask: 1 = exactly stationary, 2 = weak moving-frame visual support, 4 = just after a clip timestamp gap. Flags can combine. No image tracks are counted on the stationary plateaux. Treat those as zero relative motion, not failed odometry.

1. `tracks.py` samples by wheel distance/time and obtains masked, forward/backward-checked corner tracks. `wide.py` independently builds cross-camera, cross-time RootSIFT tracks. It caches features and pair matches under `work/poses/wide/` for this drive only.
2. `causal.py` triangulates from past rays and resects each new pose against those landmarks. Wheel increments, low-frequency fused GPS and level priors prevent drift on straights. `motion.py` handles telemetry, stops, master-clock resampling and flags.
3. `offline.py` and `bundle.cpp` optimize a continuous-time approximation to a 6-DoF trajectory and static landmarks in a CPU sparse-Schur bundle. The image factors interpolate the trajectory at each original exposure row; relative wheel/yaw factors, weak GPS and elevation priors, and an acceleration penalty connect the pose knots. It writes the two-stage solver inputs and retained geometry to `work/poses/`.
4. `validate.py` compares the deployed (not internal knot) poses, scores genuinely reserved natural tracks, and produces the plots and 10 s support table. `timing.py` checks signed fast-road residuals along the image velocity. `roadcheck.py` and `roadscore.py` independently match road-surface patches for the much harder long-range check. Neither road stage contributes a residual to the trajectory. `report.py` assembles the results.

See [REPORT.md](REPORT.md) before interpreting metre-scale or distant-point accuracy. Matching and bundle scratch files are per-drive; start with a fresh scratch directory for different footage.
