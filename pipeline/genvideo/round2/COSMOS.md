# Cosmos-Transfer2.5 test on the same drive window

The bundle contains the **actual** 81 frames at 110.0–118.0 s / 10 Hz, path-nearest undistorted front photograph, Canny edges, grayscale inverse axial depth (near = white, sequence-normalized 1st/99th percentile) and a separate white-on-black opaque-depth mask. RGB includes the IBR sky/backdrop; the depth control has no fabricated sky or far-cylinder depth. Keep the supplied FPS; do not speed up the camera path to match a vendor benchmark. The upstream API handles inputs shorter than its native 93-frame chunk. Inspect returned length, FPS and any resize before comparing drive times.

On **an already authorized Linux/NVIDIA machine** with Ubuntu 22.04+, Ampere or newer, CUDA 12.8-compatible driver ≥570.124.06, ffmpeg, uv and git-lfs:

1. Clone `https://github.com/nvidia-cosmos/cosmos-transfer2.5`; checkout `2ff49d0717af02057ae79bc75c00fbff9da1b4e7`, then `git lfs pull && uv sync --extra cu128`. Export `COSMOS_REPO` to the absolute checkout path. The upstream [setup](https://github.com/nvidia-cosmos/cosmos-transfer2.5/blob/2ff49d0717af02057ae79bc75c00fbff9da1b4e7/docs/setup.md) requires HF download access and acceptance of NVIDIA's guardrail model license. Code: Apache-2.0; weights: NVIDIA Open Model License. No weights or credentials are bundled.
2. Unzip, then `bash streetnvs-cosmos/run-cosmos.sh multi`. The precomputed edge/opaque-depth controls are weighted .45/.35; the official runner computes a low-blur RGB control at .20. `bash streetnvs-cosmos/run-cosmos.sh edge` runs the single-control baseline. These are candidate settings, not measured adherence. Reuse the native paint/photo/warp scores and inspect whether tree texture improves at fixed geometry.

**Budget, not a GPU booking.** NVIDIA lists 65.4 GB VRAM for single-model inference; their memory figure isn't a measured ceiling for three controls. For the multi-control pilot a single **180 GB B200 at $7.99/h** gives more headroom; 0.5–1.5 billed hours including an assumed cold start is **$4–12** before persistent storage and tax. A single 80 GB H100 PCIe at $3.79/h is **$1.90–5.69** for that same budget, particularly for edge-only. [Lambda on-demand rates](https://lambda.ai/pricing) checked 2026-11-21. [NVIDIA timings](https://github.com/nvidia-cosmos/cosmos-transfer2.5/blob/2ff49d0717af02057ae79bc75c00fbff9da1b4e7/docs/inference.md): 93-frame **single segmentation** 720p/16 Hz inference: 92 s on B200, 264 s on H100 PCIe; **base edge** ~180 s on B200. Cold download, safe loading and three-control inference time on this clip were **not measured**. The script keeps default guardrails. The Mac has no supported CUDA device; the documented runtime calls CUDA and requires NVIDIA. No rental, licence acceptance, credential use or CUDA generation was performed for this handoff.
