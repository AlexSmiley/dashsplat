# Stitched ground atlas v1

Read **ground/ground.json** relative to the scene. The manifest is the publication boundary; textures are immutable. Draw these tiles in stitched mode. They belong to the offline drive's ENU world, metres, Z up. Top-level `intervals` lists the reconstruction input ranges in drive seconds; it does not control tile visibility. `tiles` is an array, and each `id` is a string (`tileX_tileY`, signed integers).

- Top-level **format: "reality-ground", version: 1, colour: "camera-rgb-code"**: same display-referred RGB numbers as decoded splat DC, before the viewer grade. Apply the splat colour path, haze and night lighting once. No ICC transfer, extra sRGB decode or ACES pass if the splat shader consumes code values directly.
- Per tile: **id**, **bounds:[xMin,yMin,xMax,yMax]** (edges), **texelSize** in metres; **pixels** = interior width and height (square), **gutter** = extra texels per edge; **texture** relative to this manifest, RGBA WebP with lossy high-quality photo RGB and lossless straight alpha. Encoded dimensions both equal pixels + 2*gutter. **bytes** is compressed texture size.
- Decoded raster row **0 faces south** (minimum ENU Y), column 0 west. World XY at image index (i,j) = (xMin,yMin) + texelSize * (i+0.5-gutter,j+0.5-gutter). For west-to-east, south-to-north plane coordinates (s,t) in [0,1], raw raster UV = (gutter + pixels*(s,t))/(pixels+2*gutter). Pass bitmap without a Y flip, or invert V if the loader flips it. No overlapping geometry for gutters. Use half-open ownership `[xMin,xMax) × [yMin,yMax)` for lookups, including negative coordinates: `tileX=floor(worldX/10.24)`, `tileY=floor(worldY/10.24)`. A shared edge belongs to the east/north tile; at an absent neighbour return zero coverage rather than extrapolating the resident tile. Shared mesh vertices coincide.
- **grid:{cols,rows,z:[...]}**. Z is absolute world elevation in metres, rows south to north, columns west to east, row major; vertices uniformly spaced including both bounds. Split each cell SW–NE: triangles `(SW,SE,NE)` and `(SW,NE,NW)`, upward winding. Shared-edge vertices and neighbours' gutters use the same world samples. Render tile-local vertices as for splats.
- **alpha:"straight-coverage"**, 0 unsupported, 255 opaque surface (photographic or explicitly predicted). Premultiply before generating/filtering mipmaps (then unpremultiply before grading). **mips:"viewer-generated"**: trilinear + anisotropic filtering. 8 texels of gutter are included on each side. The interior is 1,024×1,024 (1 cm pitch) 512×512 (2 cm pitch), or 256×256 (4 cm pitch); all cover 10.24×10.24 m. Each regular height grid is 9×9. Use ordinary source-over at partial alpha. Keep loaded opaque texels in depth; soft edges should not occlude fallback splats. Depth and ground-layer suppression must precede splat composition; cars, path and upright objects remain in front according to actual depth.
- **hideGroundSplats:{layer:"ground",opaqueAlpha:0.98,heightTolerance:0.20}**: suppress confirmed ground-layer splat fragments where a resident atlas sample is opaque and the splat surface is within the tolerance of the mesh. Never remove an entire 50 m splat tile. Keep fallback through transparent pixels, during streaming and outside the atlas. Composite partial-alpha tiles over the fallback once.

### Outer ground and provenance (extension revision 6)

This remains **format version 1**. The outer extension uses existing tile bounds, gutters, height grid, texture and `texelSize`/`pixels`; there is no overlapping second mesh or radial UV convention. A mixed tile retains its original 1 or 2 cm pitch; new outer-only tiles are 4 cm. The default v5 viewer already draws these without a code change. The extension uses distance to the **trajectory**, not the playback camera: the band is 40 m, with a smooth coverage taper to zero at 44 m. Static upright structure footprints are carved out for the splats.

Optional top-level `provenance` declares a lossless grayscale PNG for **each** tile. Resolve `tile.provenance` relative to the manifest; `tile.provenanceBytes` is its compressed size. The raster dimensions, gutters, row orientation and UVs exactly match the tile's WebP. Raw byte values: **0 = unsupported, 127 = predicted, 255 = observed**. A nonzero alpha texel has exactly one of the last two labels, including in the taper. Alpha measures coverage, never confidence. `tile.bytes` is WebP bytes alone. Legacy manifests without a provenance declaration contain only photographic colour.

**Viewer change for tint/fade only:** load the mask as non-sRGB data with no Y flip; decode the class with nearest sampling at the native level. For filtered rendering, turn the codes into observed and predicted weights *before* filtering; downsample those weights multiplied by coverage alpha (never average the categorical codes). Tint the predicted contribution; for a fade, attenuate its alpha and use that same effective alpha for depth and ground-splat suppression. While the mask is unavailable, a provenance-inspection mode should show the classification as unknown. The normal published viewer currently draws both classes without tint.

### Sampling and blending without a fringe

1. Decode WebP as numeric camera RGB + **straight** coverage. In a Three.js/WebGL2 code-value shader use an RGBA8 **non-sRGB** texture, no ICC colour conversion, no upload Y flip. NW is local (s,t)=(0,1), SW=(0,0). A JPEG code value of 128 is shader input 128/255, **not** 0.216. Alpha is a linear coverage fraction.
2. Store/filter (rgb*a,a) starting at mip level zero. Premultiply exactly once before any bilinear sampling or mip generation; multiplying after sampling a straight-alpha mip is too late. For example, decode to straight bytes without premultiplication or conversion, premultiply bytes into an RGBA8 DataTexture, then generate its chain. Alternatively upload a verified premultiplied bitmap without another unpack premultiply. Each mip averages premultiplied RGB and alpha independently. Keep RGB=0 at alpha=0. Clamp to tile texture edges; do not repeat or discard the gutter before mip generation. If the filter footprint exceeds the 8-texel gutter at a shared boundary, use a neighbour-aware mip or limit the footprint near that boundary; never wrap into the opposite edge.
3. Filter once, divide filtered RGB by alpha when positive, apply the splat grade to the straight code values, then composite graded RGB times alpha with premultiplied source-over (ONE, ONE_MINUS_SRC_ALPHA). Do not let a second material sRGB/tone pass alter the result. At zero alpha skip colour/depth writes. The opaque threshold is normalized 0.98 (byte ≥250); partial samples never remove fallback depth globally. An undecoded tile contributes zero coverage and hides no splats.

A later live format would store per-texel first-seen time and successive resolution/appearance revisions with their own release times, including pose availability. At playback select the newest released revision and leave never-seen texels transparent. These offline textures and labels are not causal observations.
